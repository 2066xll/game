## 部署项目计划

### 1. 准备工作
- 确保已安装Cloudflare Wrangler CLI
- 确保已登录到Cloudflare账号

### 2. 配置检查
- ✅ KV命名空间已正确绑定：
  - SESSION_STORE: 3fb91ae014834e7e937314b377c268e5
  - SESSION_STORE_PRE: f791ee4199d44e47a5650b868c0dab3d
- ✅ D1数据库已正确绑定：
  - game-chat-db: 73606391-5970-4435-8dbe-d0be3a201d0a
- ✅ Durable Objects已在wrangler.toml中配置：
  - AuthorizationDurableObject
  - ConversationDurableObject
  - WebSocketRoom
  - ChatRoomDurableObject

### 3. 部署步骤
1. **登录Cloudflare**：运行`npm run login`命令，确保已登录到Cloudflare账号
2. **部署所有组件**：运行`npm run deploy:all`命令，该命令会执行以下操作：
   - 构建项目：`npm run build`
   - 部署Pages：`npm run deploy`
   - 部署聊天房间Durable Object：`npm run deploy:chat-room`
   - 部署WebSocket Worker：`npm run deploy:worker`
   - 部署Auth Worker：`npm run deploy:auth-worker`
   - 部署消息清理Worker：`npm run deploy:cleanup`

### 4. 验证部署
- 检查Cloudflare控制台，确保所有Worker和Durable Objects都已成功部署
- 验证KV和D1绑定是否正确
- 测试网站功能，确保所有功能正常运行

### 5. 注意事项
- 确保所有环境变量都已正确配置
- 确保Durable Objects的class_name与代码中的类名匹配
- 部署过程中可能需要输入Cloudflare账号密码或API密钥
- 如果遇到部署错误，根据错误信息进行排查和修复
