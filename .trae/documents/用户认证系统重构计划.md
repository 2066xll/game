# 用户认证系统重构计划

## 1. 数据模型设计

### 1.1 用户表结构（D1）
```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_code VARCHAR(6) UNIQUE NOT NULL,
  nickname VARCHAR(50) NOT NULL,
  email VARCHAR(100) UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  avatar_url VARCHAR(255),
  is_email_verified BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login TIMESTAMP,
  is_deleted BOOLEAN DEFAULT FALSE,
  deleted_at TIMESTAMP,
  recovery_expire_at TIMESTAMP
);
```

### 1.2 验证码表结构（D1）
```sql
CREATE TABLE verification_codes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  code VARCHAR(6) NOT NULL,
  type VARCHAR(20) NOT NULL, -- email_verify, password_reset
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### 1.3 用户会话管理（KV）
- 存储用户会话信息，键为 `session:{user_id}`
- 包含会话状态、登录IP、设备信息等

## 2. 核心功能实现

### 2.1 用户注册功能
- **路径**：`src/views/RegisterView.vue`
- **功能**：
  - 支持自定义密码设置，显示密码强度
  - 自动生成6位数字格式的唯一用户编码
  - 允许设置个性化昵称，可选绑定邮箱
  - 输入验证和防注入处理

### 2.2 登录机制
- **路径**：`src/views/LoginView.vue`
- **功能**：
  - 支持使用用户编码+密码登录
  - 支持使用已绑定邮箱+密码登录
  - 密码加密传输

### 2.3 邮箱绑定功能
- **路径**：`src/views/EmailBindView.vue`
- **功能**：
  - 支持用户注册后绑定邮箱
  - 支持修改绑定邮箱
  - 邮箱验证机制

### 2.4 用户主页功能
- **路径**：`src/views/ProfileView.vue`
- **功能**：
  - 查看用户游戏数据
  - 显示用户编码（提醒妥善保管）
  - 支持切换或注销账号（注销后保留7天）
  - 支持绑定/修改邮箱
  - 支持修改昵称
  - 支持通过邮箱验证重置密码

### 2.5 密码重置功能
- **路径**：`src/workers/auth/auth-routes.js`
- **功能**：
  - 发送密码重置验证码到绑定邮箱
  - 验证验证码后允许重置密码

## 3. 安全实现

### 3.1 输入验证
- **路径**：`src/utils/validationUtils.js`
- **功能**：
  - 密码强度校验
  - 邮箱格式验证
  - 昵称长度限制
  - 防SQL注入和XSS攻击

### 3.2 密码加密
- 使用 `bcryptjs` 进行密码哈希
- 密码传输使用HTTPS

### 3.3 验证码机制
- 6位数字验证码，有效期15分钟
- 防止暴力破解的频率限制

### 3.4 JWT和HTTP-Only Cookie
- 使用JWT进行身份验证
- HTTP-Only Cookie存储token，防止XSS攻击
